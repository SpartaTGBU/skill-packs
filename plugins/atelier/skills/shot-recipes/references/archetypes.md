# Eight original shot archetypes

Scope: promos built from captured product UI. For other film types see the Neighbours in SKILL.md.

Starting points to re-skin per product. Durations are [practice] defaults at 30 fps; slow them if
the first review says "too fast". Each shot has one lead idea.

| Archetype | Use for | Skeleton | Time |
|---|---|---|---|
| Hero spotlight | opener | Dark field, one UI card lit; push in, float, rim light traces edge, settle to rest | 3 to 4 s, last 0.5 s still |
| Deal-in grid | breadth of content | Cards arrive from one edge into real grid slots, each sooner than the last; rest when full | 2.5 to 3 s + 0.5 s rest |
| Type and filter | search/filter feature | Cursor to field, type at human speed, list narrows, one result highlights | 3 to 5 s, 0.5 s rest on the highlighted result |
| Orbit object | an asset/document | Side-tilt camera orbits a stacked card with visible thickness over dark material; pull back to scene | 3 s |
| Number roll | a metric | One stat rolls to value, label lands, hold | 2 s + 1 s hold |
| Panel pivot | before/after or modes | Two panels swap by a single rotation; the camera stays | 2 to 2.5 s, 0.5 s rest after the swap |
| Inline annotation | explain a detail | Camera eases to a region; a large-type note with marker highlight sits in page space | 2.5 s |
| Family finale | close | One representative element per shown feature flies in from several sides around the wordmark, camera crane up, stage light, then wordmark rests at least 1 s [up] | 4 to 5 s |

Recipe template to write your own (fill every line before coding):
subject; camera path; entrance curve and stagger; hold seconds; the one detail that is allowed to
glow; caption text and size; sound cue (type, frame offset); what feature it proves.
