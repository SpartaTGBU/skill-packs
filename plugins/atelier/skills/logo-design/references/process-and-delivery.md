# Process notes and delivery

## Brief (keep it short; state assumptions for gaps)
Exact name spelling; what it does; audience; 3-5 adjectives; competitors; constraints (existing colours, equity, where it must work); who decides. Write the brief in six lines [practice] and list assumptions.

## Choosing a mark type
Pick by test, in this order; the first that fits wins, and name the runner-up.
1. Name 1-6 characters and no stock-font look wanted: custom wordmark. Name over 12: monogram or symbol. In between (7-12): take the first of rules 2-6 that fits [all cut-offs practice].
2. Initial is the only thing people say about the brand: letterform. Run the letter test (mirror, rotate).
3. Symbol appears alone (avatar, favicon, app tile) on most surfaces: pictorial or abstract. Pictorial
   if one non-literal object links to the offer; abstract if two attempts at an object both failed
   the cliche check.
4. Must also read as a seal on cups, stamps, certificates: emblem, plus a stripped cut for under 32 px.
5. Audience is children or a character already exists: mascot, plus a head-only cut.
6. Wordmark and symbol will sit together in menus and on the web: combination; draw the symbol so it
   passes the 16 px test without the word.
All types: a standalone symbol then passes the footprint rule in Decision rules.

## Colour
Start from the category map, then pick one colour that is ownable in it. State HEX and RGB; give CMYK or spot values only if proofed [practice]. Verify one-colour and greyscale first. Text inside a lockup or tagline needs ordinary text contrast (WCAG ratios); the symbol itself is not bound by it but should clear about 3:1 against its usual ground [practice].

## Type and lockups
Study 3 candidate typefaces [practice] beside the symbol; match stroke weight and corner style. Fix relative sizes and spacing between symbol and wordmark in each lockup (horizontal, stacked, symbol-only, wordmark-only). Check font licences allow logo use, and outline the letters.

## Delivery set
[practice] Masters in SVG (PDF/AI/EPS if tools exist); black, white and brand-colour variants; square symbol; small-size cut; favicon (SVG plus 32 and 180 px PNG, optional ICO); app-icon tile; one-page usage notes: clear space defined by a logo element, minimum sizes, colour values, approved grounds, misuse examples. Handover note: rationale, tests run, open items.

## Redesign
Audit first: what do people recognise (shape, colour, name), what is broken (small size, dated, unscalable). Refresh keeps the recognisable core and fixes construction; rebrand replaces it and needs a reason beyond taste. Show old and new at 16, 32 and 64 px side by side [practice].

## Identity system (brief)
A mark is the seed: derive a pattern or device from its geometry, an icon style from its stroke and corner radius, and a motion rule from its construction. Hand these to design-systems and motion-design.

## Studying a reference library
Any collection (a book, a site, a folder of SVGs) is for study. Procedure:
1. Before concepts, pick the category and note its dominant shapes and hues from the index or search:
   open at most 20 files [practice], enough to see the crowd without absorbing it.
2. For each, record in a notes file only: shape family, colour count, anchor count, stroke vs fill. Not
   the drawing.
3. Open 3 sources [practice] to see how few anchors clean arcs need; then close them.
4. Draw your concepts without the tabs open.
5. Copy-check each survivor: render it and the nearest reference mark solid black at 64 px, same
   canvas, and overlay at 50% opacity. Fail if the shared area exceeds roughly 60% of the smaller
   silhouette [practice]; change the idea, not the details.
6. Collections over-represent some sectors, so confirm their conventions fit yours.
Nothing from a collection goes into your file; never trace or recolour.
