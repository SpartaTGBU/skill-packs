# Brand design-system sources

Two corpora feed DESIGN.md authoring.

1. **Bundled (offline):** `~/.claude/local-plugins/forge-marketplace/plugins/atelier/skills/visual-design/references/brands/<site>.md`, 54 brands as prose plus exact CSS values (palette roles, type hierarchy, components, spacing, shadows). Catalog and font substitutes: `visual-design/references/brand-catalog.md`.
2. **Bundled (offline), VoltAgent/awesome-design-md (MIT), 74 brands in token form:** `~/.claude/local-plugins/forge-marketplace/plugins/atelier/skills/design-systems/references/brands/<brand>/DESIGN.md`. Each already follows the YAML-front-matter spec above, so copy it as a starting point, edit, and lint. Upstream: github.com/VoltAgent/awesome-design-md (MIT, see LICENSE-awesome-design-md.txt).
