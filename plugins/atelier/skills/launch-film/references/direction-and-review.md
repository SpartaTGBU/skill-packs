# Direction, treatment and cold review

Used in Stages 2-3 (choosing and documenting a direction) and Stage 7 (independent review).
Tags: [up] = in MIT huashu-motion; [practice] = our judgment.

## Pick a visual language for the shape
Candidate languages per shape; use the first that suits, and give a second shape its own language
only if the change means something.

| Shape | Candidates |
|---|---|
| claim | kinetic type, generative field, single object, ident |
| workflow | cursor demo, morph |
| mechanism | drawing or system diagram |
| evidence | data story, collage |
| list | type chapters, grid, one object morphing per item |
| transformation | morph, split compare |
| story | photo-led, character, hand-drawn |
| showcase | one deeply made artifact |

## Show three directions
- Differ in motion language, structure and material use. A colour swap is not a direction.
- Palette is the product's own, with the source named; check text contrast before showing.
- Each is one real key frame plus a card with four lines: language, palette source, what lands, why it fits.
- Exactly one uses depth (so flat can be compared with spatial); the other two use no z-axis camera move.
- Skip the step if the user named a style or the project already has one.

## treatment.md contents, in order
1. Chosen direction, route, one-sentence thesis.
2. Rhythm sheet and beat map; columns `bar.beat | time | event | move | sound`.
3. Four rendered stills: hook, hero, densest moment, end. A still that fails as a poster is reworked.
4. Continuity chain, one line per transition.
5. Music world, tempo, a reference piece.
6. Show this to the user before building when the film is over about 15 s [up] or the user is picky [practice].

## Cold review brief
Give the reviewer: the request, the final MP4, the chosen direction, the treatment, a list of every
claim on screen with its source (unsourced copy is treated as invented), and the facts to check.
Do not explain intent. Ask where attention drops.

Each finding carries timecode, defect, severity. The reviewer also states what was and was not
watched, tied to the file hash. Defect classes:
- unclear message; logic error; unreadable text
- craft faults: aliasing, jitter, font fallback
- monotone rhythm (boundary diff under 2)
- a camera move with no verb or target in the shot list
- technical fault

Judge stills and motion separately. After fixes: re-check the original defect and the neighbouring
seams; rework from the last delivered version, not from scratch.

## Notes kept across films
File each note as one of: user's words (preference), seen once (observed), seen in two films or
measured (verified). One user's taste never becomes a general rule.
