# Review rounds

Goal: each comment becomes one small, traceable edit.

1. Collect comments as `target id: wanted change`. If a comment names no target, give it one
   (add an id) before editing.
2. Group by block. Resolve conflicts between comments by asking, not guessing.
3. Copy the file to `name-vN.html` first; edit the working copy only in the named blocks.
4. Add a top-of-file comment: round number, date, one line per changed id.
5. Re-run the Verify list in SKILL.md on affected widths only, plus the console check.
6. Reply per comment: done, not done with reason, or needs decision. Never silently drop one.
7. If three rounds [practice] keep touching the same block, the brief is unclear: restate the point
   sentence to the owner and confirm before a fourth.

Handing on: send the single file; say which parts are invented; say the fidelity level.
No extra tooling is needed: comments can arrive as plain text with ids, and the file stays valid standalone.
